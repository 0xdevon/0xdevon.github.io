# Devon Chan's Blog

[中文](#中文) | [English](#english)

## 中文

这是 Devon Chan 的个人博客静态站点，主要记录编程学习、技术实践与个人随笔。

- 在线访问：[blog.devonchan.com](https://blog.devonchan.com)
- 站点生成器：[Hugo](https://gohugo.io/)
- 主题：[Eureka](https://github.com/wangchucheng/hugo-eureka)
- 托管方式：GitHub Pages

### 内容与目录

- `posts/`：技术文章
- `essays/`：个人随笔
- `docs/`：文档内容
- `tags/`、`categories/`：标签与分类页面
- `css/`、`js/`、`images/`：静态资源
- `CNAME`：自定义域名配置

### 本地预览

该仓库保存的是已生成的静态文件，可直接启动一个本地 HTTP 服务：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## English

This is Devon Chan's personal blog, featuring notes on programming, hands-on technical topics, and personal essays.

- Website: [blog.devonchan.com](https://blog.devonchan.com)
- Static site generator: [Hugo](https://gohugo.io/)
- Theme: [Eureka](https://github.com/wangchucheng/hugo-eureka)
- Hosting: GitHub Pages

### Content and Structure

- `posts/`: Technical articles
- `essays/`: Personal essays
- `docs/`: Documentation
- `tags/`, `categories/`: Tag and category pages
- `css/`, `js/`, `images/`: Static assets
- `CNAME`: Custom domain configuration

### Local Preview

This repository contains the generated static site. Start a local HTTP server with:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
